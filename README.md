# Ashley Roselynn Vincent — Engineering Portfolio

Open index.html to view the portfolio. Keep the assets folder, styles.css,
script.js, and reports.js alongside it. No build process or package install is required.

## Add the PDF reports
Place the PDFs in reports/ and edit reports.js, replacing the matching null with
'reports/your-file.pdf'. Each report then appears inline in its project's documents
area, with an additional link to open it separately. Until supplied, the slot
reads "PDF coming soon" and does not load a missing file.

## Publish
Upload this folder's contents to a static website host. index.html must be at the
site root. Images and the résumé are separate files, so the HTML remains small.
The two Google Sheets links keep their existing Google permissions.

## Editing
index.html: text and project structure.
styles.css: palette, spacing, typography, and responsive layouts.
assets/: optimized images and the résumé extracted from the supplied HTML.
reports.js: future PDF report locations.

The separate Ashley-Vincent-Portfolio.html is a self-contained review copy.
Use this folder as the editable website source when adding reports or publishing.
Poster photos are presentation photographs, not original poster PDF files.

## Current structure
Seven independent sections, in order: Rocket Project Liquids, Heart-on-a-chip Research, Ergonomic Autoinjector, Pill Dispenser, Autonomous Rover, Ackermann Steering Rover, MedTech Founders Program.
Each section contains a brief description, gallery, and documents/links.
Labeled placeholders intentionally await further images and PDFs.

Each project has 12 equally sized image slots: four columns by three rows on desktop, two columns on smaller screens. Explore uses dark purple and blue controls with white labels.
